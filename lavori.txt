# IL FILO DI TAMARA - elenco dei lavori
#
# Una riga = un lavoro, scritta cosi':
#     Nome del lavoro | Categoria | nome-foto.jpg
# Se un lavoro ha piu' foto, separale con la virgola:
#     Pochette gialla | Borse | pochette-gialla.jpg, pochette-gialla-interno.jpg
#
# - Le foto vanno caricate nella cartella "foto" (jpg, png o webp).
# - Si puo' aggiungere anche un VIDEO (mp4): caricalo nella cartella "foto"
#   e scrivilo DOPO la foto, che fa da copertina. Aprendo il lavoro parte il video:
#     Borsa verde | Borse | borsa-verde.jpg, borsa-verde.mp4
#   Dal sito di GitHub si caricano file fino a 25 MB.
# - I lavori compaiono sul sito nell'ordine di questo elenco: i nuovi mettili in alto.
# - Le categorie si creano da sole: basta scriverle (es. Borse, Casa, Decorazioni).
# - Per NASCONDERE un lavoro senza cancellarlo, metti # all'inizio della riga.
# - Le righe che iniziano con # non compaiono sul sito.
