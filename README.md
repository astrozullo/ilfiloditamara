# Il Filo di Tamara

Galleria dei lavori all'uncinetto di Tamara.

## Aggiungere un lavoro (dal sito di GitHub, anche da telefono)

1. Apri la cartella `foto` → **Add file** → **Upload files** → carica la foto → **Commit changes**.
2. Apri `lavori.txt` → icona della matita → aggiungi in alto una riga:
   `Nome del lavoro | Categoria | nome-foto.jpg` → **Commit changes**.
3. Dopo 1-2 minuti il sito è aggiornato.

Attenzione: il nome della foto in `lavori.txt` deve essere identico al file,
maiuscole comprese (`Borsa.JPG` e `borsa.jpg` sono due file diversi).
